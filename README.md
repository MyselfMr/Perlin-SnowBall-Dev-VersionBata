# Perlin Snowball
**Beta 1 | Minecraft 1.20.1 Fabric Mod**

> 投掷雪球，撞击方块后生成基于柏林噪声的程序化地形。
> Throw a snowball to generate procedural terrain using Perlin noise upon impact.

⚠️ This is a beta version. Terrain generation may cause lag and has unresolved bugs.
⚠️ 这是Beta测试版，地形生成可能造成卡顿，存在未修复BUG。

## Requirements 依赖
- Minecraft 1.20.1
- Fabric Loader
- Fabric API

## How to use 使用方法
1. Install Fabric API and this mod
2. Join the world, you will automatically get the special snowball
3. Throw the snowball at a block to spawn terrain

1. 安装 Fabric API 和本模组
2. 进入世界，自动获得特殊雪球
3. 将雪球投向方块，即可生成地形
